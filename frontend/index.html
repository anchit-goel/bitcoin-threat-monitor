On the numbers

Every figure on this page is real and independently verifiable — pulled from a running backend, not written by hand. The dashboard's synthetic-data performance (96–99%) is reported only as "detects the laundering patterns we modelled," never as real-world accuracy.

Benchmarked separately against real Elliptic transaction data, our structural graph features scored close to chance (ROC AUC 0.685, precision@50 of 8% — worse than random). That result is published, not buried, because a security tool's credibility depends on knowing exactly where it does and doesn't work yet.
